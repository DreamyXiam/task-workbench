# 管理界面与权限说明

界面参考 [Beautiful UI](https://www.beautifului.dev/) 的记录列表、筛选表格和侧栏结构，继续使用项目现有 Vue、Element Plus 与浅深色主题，不依赖该站点运行时代码。

## 统一样式

- 页面：标题、简短说明、主要操作；内容使用白色或深色表面、细边框、低阴影。
- 记录：主要动作在首行，人员、公司、对象为次级信息；时间与状态靠右，详细信息在居中卡片中查看。
- 查询：关键词、类型、时间和查询/重置组成同一工具条；手机端自动单列。
- 权限：可启用、已关闭、因依赖未生效和角色不支持分别展示；全局管理员单独标识为固定权限。
- 沿用全站字号、间距、圆角、焦点、浅深色颜色变量与减少动态效果设置。

## 统计与考核

全局管理员可查看全范围统计、考核得分和计算批次。公司领导/分管领导、集团领导与部门负责人仍按原组织范围读取。公司管理员仅维护考核批次和模板，不获得业务统计或得分权限；统计入口随实际权限隐藏。

全局管理员计算考核时先选择所属公司；考核得分查看不会赋予领导调分与申诉权限。管理员的计算/解锁仍需近期二次验证，测试账号沿用测试站当前豁免策略。

## 操作日志

支持关键词（人员、公司、原始动作编码、追踪号）、动作类型和北京时间日期区间筛选、分页、详情及 Excel/CSV 导出。导出使用最近一次查询条件，最多5000行，保留水印、近期验证及导出频率限制。

| 显示字段 | 数据来源 |
| --- | --- |
| 日志编号 | audit_event.id |
| 操作时间 | audit_event.created_at；界面转为北京时间，导出标明UTC |
| 操作人、操作人ID | app_user.name、audit_event.actor_id |
| 公司、公司ID | company.name、audit_event.company_id；0表示全局 |
| 操作说明、动作编码 | 服务端中文映射、audit_event.action原值 |
| 对象类型、对象编号 | 动作分类、audit_event.object_id；0为汇总操作 |
| 代理授权ID | audit_event.delegation_id |
| 追踪号 | audit_event.trace_id |

人员与公司名称为当前目录名称；日志本身不可编辑，历史未记录的修改前后值不会补写。认证凭据、业务完整载荷和审计链内部字段不在查询或导出内容中。集团领导与全局管理员可看全范围，其他领导与公司管理员只能看本公司。

## 岗位及权限

岗位页提供职责、记录数量及生效状态摘要，可按人员/公司/部门搜索任职与代理记录。交接流程继续保留选择任务、指定接收人和填写原因。

权限配置左侧选择角色，右侧按任务、协作分析和系统管理分组。关闭“查看任务”时依赖功能显示不可用；保存前确认，切换角色或离开页面时提示未保存调整。保存仍使用版本校验、近期验证、审计和相关角色会话失效。
