# 任务界面与汇报指南

更新日期：2026-11-08。页面操作以当前岗位、组织范围及服务端 `allowedActions` 为准。

## 任务展示

任务中心默认采用卡片，展示状态、优先级、责任部门、负责人、截止时间、最新文字进展和更新时间。点击卡片任意位置或聚焦后按 Enter 可打开详情，也可通过链接菜单在新标签页打开。

工作概览、任务中心、我的任务、甘特图、部门执行、独立子任务和汇报历史均不显示任务进度百分比或百分比进度条。逾期单独标记，当前状态由服务端返回；填写进展说明不会自动变成已完成。

任务详情顶部集中展示公司、主办部门、截止时间、优先级和部门执行操作；桌面右侧栏集中展示“任务进展”与“沟通记录”，窄屏自动改为上下排列。“进度记录”合并到“任务与执行”内容下方，右侧“查看进度记录”可直接定位到该区块。详情页不再单独展示“任务填报”和“操作时间线”；原有部门进展和历史字段汇报统一在“进度记录”中查看，后台操作审计继续保留。

## 汇报与状态更新

1. 在任务详情顶部的“部门执行”选择“更新进度”，填写必填的进展说明后提交；无需填写百分比。
2. 按业务流程接收任务、分派人员、提交成果、汇总上报及验收。按钮仅在当前岗位和状态允许时出现。
3. “子任务”中的独立事项通过“更新状态”选择“进行中”或“已完成”，再保存。该状态更新不会替代部门成果提交或主任务验收。
4. 汇报历史保留原始说明和时间。界面不会根据最新状态倒推每一条历史记录当时的流程状态。

## 甘特图与多年任务

- 在任务中心切换至“甘特图”。图表展示当前筛选页，沿用查询、分页和每 30 秒刷新。
- 默认显示当前月份，可选择“全周期／月／周／日”。全周期概览保留全部任务时间跨度，主轨道显示所选窗口，适用于一年或多年的任务。
- 拖动概览选框浏览其他时段；用前后按钮、日期输入或“今天”定位。不在当前视窗的任务可点击“定位任务”。
- 上轨表示任务创建至截止日期；下轨按部门进展和重点工作实际填报时间分段。点击片段或拖动时间指针，在下方查看汇报内容、来源和原始时间。
- 跨窗口片段会被截取展示，边缘箭头表示仍向窗口外延续；原始记录时间保留。没有汇报的区间明确显示“尚无汇报”。最后一次汇报的延续区域不代表期间持续发生更新。
- 缩放查看更细的记录，拖动轨道空白处平移。时间指针可用方向键按小时微调，Shift 按天调整。自动刷新保留当前指针和视窗状态。
- 时间均按北京时间展示。拖动和缩放只影响浏览，不会修改期限、汇报时间或业务状态。

## 数据与接口兼容

现有接口和历史数据库中的 `percent`、`reportedPercent` 等字段暂时保留，以兼容已有客户端和数据。本次调整不删除或重算历史数值；前端汇报说明时沿用原有内部值，独立子任务状态通过现有接口的完成值映射提交。

统计完成率与 KPI 指标遵循各自的统计和考核口径，不作为单项任务填报的进度百分比。

演示数据应明确标记为“【演示】”，模拟历史仅用于展示，不作为实际业务汇报或考核依据。
