## Global Constraints
- No production access or real data; do not modify parent scripts/docs.

## Fixed integration contract
API prefix /api/v1. JSON envelope {code:"OK",message,data,traceId}, errors use HTTP400/401/403/404/409/422/429 with code/message/traceId.
Dates ISO8601; timezone Asia/Shanghai.
GET/auth/csrf returns data{token,headerName}; POST/auth/login JSON{account,password,totp?,recoveryCode?}; POST/auth/logout; GET/auth/me.
Me fields{id,name,accountSuffix,role,companyId,deptId,mustChangePassword,totpRequired,totpVerified,scopes:[{id,role,companyId,deptId}]}; POST/auth/context {scopeId}.
POST/auth/change-password {oldPassword,newPassword}; POST/auth/totp/setup, /confirm{code}, /verify{code}, /recover{recoveryCode}.
Role values GROUP_LEADER/DIVISION_LEADER/COMPANY_LEADER/DEPT_HEAD/EMPLOYEE/ADMIN.
GET/tasks and /sub-tasks/mine paginated data{items,page,pageSize,total}; task camelCase fields{id,code,title,content,companyId,priority,status,deadline,everOverdue,version,hostDeptId}.
GET/tasks/{id}: task fields plus subTasks/comments/progress/timeline/attachments/deadlineRequests/collaborationRequests arrays.
POST/tasks {title,content,companyId,priority,deadline,hostDeptId,collaboratorDeptIds}; POST/tasks/match {title,content,companyId} returns suggestions[{deptId,deptName,role,score,reasons}],ruleVersion.
POST/tasks/{id}/confirm-assign, /accept, /reject{deptIds,reason,version}, /cancel{reason,version}, /deadline{deadline,reason,version}, /summarize{allowGap,reason,version}, /urge.
POST/sub-tasks/{id}/receive,/assign{userIds,ownerId},/progress{percent,note},/submit{summary,version},/withdraw{reason,version},/extend{deadline,reason},/transfer{userId,reason}.
POST/tasks/{id}/comments{content,mentions}; POST/deadline-requests/{id}/approve or /reject{reason}; GET/collaborations; POST/collaborations/{id}/accept or /reject{reason}.
GET/admin/companies,/departments,/users,/tags,/rules,/notification-channels and CRUD writes for ADMIN; GET/organization/departments and /users provide authorized business option lists.
GET/stats/overview returns{total,inProgress,pendingAcceptance,overdue,completed,recentTasks}; GET/stats/dept; GET/stats/export is safe CSV/Excel compatible with authorized scope.
GET/notifications paginated; POST/notifications/{id}/read; POST/notifications/archive.
GET/kpi/scores?period=YYYY-MM&companyId, GET/kpi/runs, GET/kpi/templates; POST/admin/kpi/runs{period,companyId,templateId,simulation}; POST/kpi/scores/{id}/appeals{reason}; POST/kpi/appeals/{id}/resolve{decision,reason}; POST/kpi/scores/{id}/adjust{score,reason}; POST/admin/kpi/runs/{id}/unlock{reason}; GET/kpi/export.
Uploads POST/attachments multipart fields file,taskId,subTaskId; GET/attachments/{id}/download,/preview,/versions; quarantined files never downloadable.
All writes Idempotency-Key UUID except authentication and CSRF. API produces allowedActions so frontend honors but never relies on UI for security.
