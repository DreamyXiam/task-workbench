# 任务自定义填报与领导协调实施计划

**Goal:** 在任务中提供可增删排序的自定义字段、填报历史、领导协调和重点工作汇总。

**Architecture:** 字段定义及当前值保存在任务业务记录，独立历史记录追溯变更；服务端校验既有任务权限和版本。创建页、任务详情和任务中心复用既有 API 与组件。

**Tech Stack:** Spring Boot、Java 21、Vue 3、TypeScript、MySQL/H2。

**Spec:** `docs/superpowers/specs/2026-11-08-key-work-coordination-design.md`

## 步骤

1. 服务端先编写失败测试，覆盖字段类型、必填、删除保留历史、权限、组织隔离、并发版本及反馈；实现任务字段配置、填报和协调的事务操作。
2. 创建页面实现预设、添加及拖动/键盘排序；详情实现字段编辑、配置、历史及领导反馈；任务中心实现重点工作筛选和汇总。
3. 补充前后端验证并审阅权限及变化范围。完成后推送工作分支、创建依赖 PR 并检查 CI；备份并部署测试站点，验证健康和访问。

## 审查重点

- 无权参与任务的账号直接访问及跨公司协办身份不能越权写入。
- 旧版本提交和相互并发不能覆盖字段定义或他人的填报。
- 删除、重命名和选项变更不会悄悄丢失已填写数据。
- 数值、日期、选项、必填和恶意输入在服务端验证。
- 普通任务、代理身份及已完成或取消任务保持现有授权边界。
