# 任务自定义填报与领导协调设计

## 目标与方案

在现有任务中心和任务详情支持可配置字段，让布置人按工作需要增减、命名和拖动排序；发布后仍可调整。以用户提供的《各部门2026年重点工作及近期急需领导协调解问题表》为预设，支持部门填报和领导协调。任务保存字段定义与填写内容，复用任务、子任务、附件、角色和组织权限。另建表单会重复管理任务和权限，固定字段不能满足灵活配置的要求。字段配置属于各自任务，不自动修改其他任务。

## 创建与调整字段

- 布置任务时可使用重点工作预设：工作内容、推进情况、存在问题、解决建议、需要领导协调解决的工作、时间要求、备注。工作内容和时间要求分别复用现有任务标题及内容、截止时间，避免数据不一致；其余为可配置字段。
- 保留公司、主办部门、优先级、任务标题、任务要求和截止时间等必要业务字段；自定义字段可添加、命名、删除、拖动排序，并提供键盘可操作的上移、下移按钮，可设置是否必填。
- 字段类型支持文字、数字、日期、下拉单选；选项可配置。每个字段有稳定内部标识，重命名或排序不会改变已有数据。
- 发布后有权管理该任务的人员仍可增减、重命名及排序；移除时明确提示，已填内容保留在历史记录中，不再出现在当前表单。已填写字段不能直接更改类型；下拉选项变更不得使已有值静默丢失，应保留历史并要求先处理冲突。
- 配置和填报使用版本校验；字段定义发生变化后旧表单提交应提示刷新，避免覆盖他人修改。

## 填报、协调与汇总

- 任务详情按字段配置显示可填写内容，有权查看任务的人可见；修改记录操作者、时间和变更前后内容。
- 重点工作预设提供领导协调状态与反馈，状态为“无需协调、待协调、协调中、已解决”。新增或变更协调事项后可重新进入待协调状态；反馈保留历史。
- 任务中心可筛选重点工作并查看汇总。汇总以任务为行，包含公司、主办部门、时间要求和预设字段；其他自定义字段在详情显示，避免不同任务定义的列被错误合并。汇总沿用现有可见范围和分页。
- 详情继续提供子任务、进度、附件和留言。自定义填报与既有任务进度记录使用明确名称，不暗示二者自动同步。

## 权限与数据安全

- 服务端校验任务可见性、角色功能权限、组织范围和任务状态；不能通过更改字段获得额外任务或跨公司访问权限。
- 字段配置由有权管理该任务的领导或全局管理员维护（公司领导须为任务创建人，集团领导按既有范围管理）；填报由所属公司主办部门负责人、经主办子任务授权的承办人员，以及对应范围的领导和全局管理员进行。主办部门人员在接收任务后、提交成果前填报；领导协调状态和反馈由有权管理任务的领导或全局管理员维护。
- 跨公司协办者在现有授权成立后按任务可见性查看，不自动获得主办部门填报、字段配置或领导反馈权限；委托身份不能扩大原有委托范围。
- 字段定义、名称、选项、数量和值受服务端限制与类型校验；写入使用既有 CSRF、幂等、事务、版本和审计机制。删除为逻辑移除，历史记录不得泄露给无任务访问权的人。

## 验证与发布

覆盖普通任务兼容、预设及自定义字段、拖动及键盘排序、发布后调整、删除后的历史、各类型校验、必填、下拉选项冲突、版本冲突、角色功能开关、跨公司越权、领导反馈和汇总。测试通过后提交并推送无 `codex/` 前缀的工作分支，创建依赖现有角色权限 PR 的 PR 并等待必需检查；部署测试服务器前备份数据库和附件，完成健康及访问检查。本次不包含原 `.xls` 文件直接导入、原样导出或跨任务复用模板管理。
